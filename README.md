# Personal Projects

Things I build outside of work, mostly around financial data and the analytics on top of it.

## Projects

### [Ledgerline](ledgerline/) — portfolio analytics dashboard

A portfolio analytics dashboard in a single HTML file: time-weighted and money-weighted returns, asset-versus-currency
P&L attribution, a five-factor equity model, and risk analytics. No build step, no dependencies, no network calls.
All data is synthetic and generated in-browser; the analytics computed on top of it are real.

**[Live demo](https://savvassoteriou223.github.io/Personal-Projects/ledgerline/)** · [Source and write-up](ledgerline/)
