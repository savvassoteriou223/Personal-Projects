# Helix — Full Split / Exercise / Set / Rep Reference

**How to read this:** each split is the actual training week — Day 1, Day 2, … Each day is done ONCE per week. The "weekly volume" tables sum every set of a muscle ACROSS ALL DAYS in that week. So a 2-day full body trains quads on both days, and the weekly quad total = Day 1 + Day 2 added together.

_Block 1 picks, "Build muscle" goal (4 compound / 3 isolation sets), full-gym equipment. Bold rows = men and women differ. Sets counted to the primary mover; optional days/exercises (marked "opt") are NOT counted in weekly totals._
